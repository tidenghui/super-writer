# @tidenghui/contract

一本书长什么样。

这一层只有两件事：

1. **类型**——书、章、伏笔、事实、角色特征、物件、数量账本
2. **读写**——按目录约定从磁盘读出、原子写回

它不依赖引擎，也不依赖阅读器。**这是写手和阅读器之间唯一的契约。**

```
books/<slug>/
  book.json          书名、简介、题材、作者
  bible/             命题、世界、文风、人物、大纲、伏笔、规则
  chapters/          正文 .md + 每章 .meta.json
  canon/             事实表、伏笔账本、角色特征、物件名录、数量账本
```

改这一层等于改数据格式，两边都要跟着动。
