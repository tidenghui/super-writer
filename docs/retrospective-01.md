## 二、问题清单（按影响排序）

### 1. 高潮依赖从未铺垫的规则（结构性，最严重）

终章卡了 7 次。根因不是文笔，是**结局需要的能力，前 29 章没给**：
「落笔即成书」「笔点干血能显出字」——这两条规则一条都没埋过。

**已修**：章纲新增 `requires`，引擎逐条回查书里有没有，没有就退回重写。
**未修**：没有「倒推埋设计划」。引擎只会**发现**缺口，不会**回头去补**。
下一篇必须在动笔前把"结局需要什么→哪一章埋"排出来。

### 2. 写手会凭空造"具体物"

最高频的一类硬伤：需要一个东西来承接情节，就随手造一个，还用「那根麻绳」
这种理所当然的口气。第 23 章凭空造过一个姐姐。

**部分修**：引擎从正文抽物件名录与角色特征，按场景相关度喂给写手。
**未修**：这是生成行为的固有倾向，压不到零。靠修订兜底，代价是每章多一轮。

### 3. 人称／属性一致性没有可靠的机械检查

第 21 章把阿满写成"她"，已经发布。之后每一章用"他"都被判"与前章冲突"，
连累第 27、28、30 章反复失败，最后靠人工批注修了两个字。

**未修**。试过代词检查，13 章正式稿误报 4/4——段里有名字不代表代词指他。
**方向**：对配角强制用名字、少用代词（写进起草规则），比事后检查可靠。

### 4. 章纲写得太细，错误一路下传

章纲曾规定颜色、气味、具体手势，那些细节它没有事实表可核对，写错了，
正文忠实照抄。第 15 章的"两短一长"就是这么来的。

**已修**：章纲限制为结构（每条 ≤70 字），细节留给起草。

### 5. 修订有时让稿子更差

多章出现"修订之后反而变差"，靠回退兜住。回退是安全的，但那一轮钱白花。

**部分修**：仲裁的意见作为最高优先级喂给修订。

### 6. 冷读量表饱和，测不出质量梯度

30 章全部 3/3。它能把"烂稿"和"真稿"分开（`npm run calibrate` 验过），
但在真稿之间没有分辨力。**等于我们没有可优化的目标函数。**

**未修**。需要一个更狠的量表：强制排序、预测题（"下一章会怎样"）、
或者"你愿意为下一章付钱吗"。

### 7. 评分不落盘

meta 里没有分数，无法分析趋势。**未修**，小事但影响后续所有决策。

### 8. 没有真人反馈

全部验收都是模型扮演的读者。真正的用户是第一个真人。

## 三、我这一路做错的事

**我反复替系统写东西。** 用户提醒了四次。

手写过：整本故事圣经、第 1 章开头、第 3 章结尾、第 10 章的动作、第 5/12 章的节拍、
6 个角色的签名特征、前 20 章的天数。

每一次的借口都是"这不是写作，是补数据"。在这个项目里，数据即写作。

**代价**：系统的真实能力被我的手遮住了。我报的通过率，是"系统 + 我"的通过率。

后来写进 AGENTS.md 第零原则：`books/` 下的内容只能由引擎代码路径写入。

## 四、对「自主写完一篇中篇」还缺什么

| 能力 | 现状 | 下一篇需要 |
|---|---|---|
| 出题（premise / 世界 / 人物） | **人写** | 引擎从一句种子生成 |
| 卷纲 | 人写 | 引擎生成 |
| 章纲 | 引擎写 ✓ | 保持 |
| 前置条件回查 | 有 ✓ | 保持 |
| **倒推埋设计划** | **无** | 从结局倒推，把前提分配到各章 |
| 正文起草 | 引擎写 ✓ | 保持 |
| 机械检查 | 有（引号／禁忌／串味／前置） | 补：配角名字化 |
| 修订 | 有 ✓ | 保持 |
| 归档（事实／伏笔／特征／物件／规则） | 有 ✓ | 保持 |
| 无人值守续写 | `write` / `backlog` 有 | 补：跑完整本不中断 |
| 质量度量 | 冷读饱和 | 换更狠的量表 |

## 五、下一篇的计划

**目标**：引擎从一句种子出发，无人干预写完一部中篇（12–16 章，3–5 万字）。

**做法**：

1. **出题环节交给引擎**：人给一句种子 + 一句结局方向，引擎产出 premise、
   世界、人物、卷纲，人只审不改。
2. **倒推埋设**：从结局方向推出"必须成立的前提"，分配到各章作为 `plant`，
   写正文前先校验每一条都有落点。
3. **配角名字化**：起草规则里要求对配角用名字少用代词，绕开人称检查的不可靠。
4. **评分落盘**：meta 存各批评家分数，能看趋势。
5. **跑完为止**：`write` 跑到最后一章，中途失败自动重试，超出预算停。
6. **不手改**：整本写完之前，我不碰任何文件。

**验收**：整本自动跑完，我在最后读一遍；如果哪一章被人工修过，那次实验就算失败。
